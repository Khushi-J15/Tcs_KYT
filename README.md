# 100 MOST REPETITIVE KYT MCQS ASKED IN TCS IPA

### Story of this project
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; I recently cleared TCS exam. As a result, TCS sent me course content in XPLORE to complete before joining. It's not mandatory to finish them, but it's recommended to learn about the organization and courses shared in the XPLORE program.\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; As a part of the XPLORE program, new candidates also have to give an internal IPA exam. This exam has a section called KYT (Know Your TCS). To practice this section, I found a YouTube video on internet by [BrainyBeast2.0](https://www.youtube.com/@brainybeast2.0) which has 100 most repetitive questions asked in the KYT section.\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Since I got the question set I was looking for, I started to practice and found some patterns in the video. The curious developer inside me noticed these patterns and I decided to build this project. So I used machine learning to extract questions from the video and React.js for the frontend to practice the questions.
